# متابعة الحفظ — تطبيق موحّد (v5)

تطبيق PWA واحد يجمع «متابعة مسار الحفظ» (الورقة والتقرير والمتعلمون) و«متابعة الحفظ والتثبيت والمراجعة» (المسار والمراجعة المتباعدة والإشعارات)، بلا أدوات بناء.

## الشاشات

| التبويب | المحتوى |
|---|---|
| اليوم | المراجعات المستحقة، الورد، **خطة التقوية**، المقاطع قيد الحفظ، سلسلة الأيام |
| الحفظ | مقطع جديد: 9 تكرارات عقلية ثم لسانية (30 فأكثر) |
| المراجعة | مراجعة متباعدة (3 أيام، 7 أيام، شهر) بتقييم متقن / متردد / ضعيف |
| الورد | مراجعة السور أسبوعيًا + **جدول الأسبوع** (تلقائي أو يدوي، مع طباعة) |
| السجل | **السجل**، و**ورقة المتابعة**، و**التقرير الشهري** |
| زر «سجّل حفظي» | نافذة إدخال: الكمية، تقييم الحفظ، إجراءات التقوية |

### نافذة «سجّل حفظي»
- النوع: حفظ جديد، جوار الدرس، مراجعة القريب، مراجعة البعيد، تقييم جودة.
- الكمية: السورة ومن آية وإلى آية، **كلها قوائم اختيار**.
- التقييم: متقن، متردد، ضعيف. يقترح التطبيق إجراءات تقوية مناسبة ويحدّدها لك.
- إجراءات التقوية (10): التثبيت، الربط، إعادة الحفظ، التجزئة، الاستماع، الكتابة من الحفظ، التسميع، ضبط المواضع، القراءة في الصلاة، ضبط المتشابهات. تظهر في «خطة التقوية» بشاشة اليوم لتعلّمها منجزة.
- الربط بالمسار: يبدأ المقطع الجديد في المسار، أو يُعتمد التقييم مراجعةً لمقطع مستحق، أو يُعاد المقطع الضعيف إلى الحفظ اللساني.

### ورقة المتابعة (السجل ← ورقة المتابعة)
نسخة من الورقة الورقية «متابعة المحفوظ»: جدول **المعاهدة** (اليوم والتاريخ، نوع المعاهدة: جوار الدرس / مراجعة القريب / مراجعة البعيد، المستمع، المقدار، الأخطاء، التنبيهات، الملاحظات) وجدول **الدرس الجديد** (نوع الدرس، المقدار، الملاحظات، الإنجاز). زر الطباعة يُخرجها بشكل أفقي بأسطر فارغة للكتابة اليدوية.

## الملفات

## الترحيل من التطبيقين القديمين

- عند أول فتح على **نفس الرابط** القديم تُنقل البيانات تلقائيًا: بيانات المسار إلى متعلم «حفظي»، وكل متعلم في تطبيق الورقة إلى متعلم مستقل بسجلاته.
- دروس «تم» في الورقة القديمة تصير مقاطع «مثبّتة» (تُحتسب في المحفوظ والورد).
- على رابط جديد: صدّر نسخة من كل تطبيق قديم، ثم «الإعدادات ← استيراد» (يقبل الصيغتين).

## النشر (Netlify)

ارفع المجلد إلى GitHub ثم Add new site ← Import from Git (السحب والإفلات لا يثبّت حزم الدوال). التطبيق يعمل دون الإشعار المضمون؛ لتفعيله:

1. `npx web-push generate-vapid-keys`
2. Netlify ← Environment variables: `VAPID_PUBLIC_KEY` و`VAPID_PRIVATE_KEY` و`VAPID_SUBJECT` (مثل `mailto:you@example.com`)
3. أعد النشر، ثم من الهاتف: ⚙ ← «تفعيل الإشعار المضمون» (على آيفون أضف التطبيق للشاشة الرئيسية أولًا).

## ترقيم الآيات

الافتراضي ترقيم حفص (6236 آية) كما في التطبيقين. لرواية ورش: ⚙ ← «ترقيم الآيات» ← مخصص، ثم الصق أعداد آيات السور الـ 114 بترتيب المصحف.

## التحديث

عدّل الملفات ثم غيّر `VERSION` في `sw.js` ليتحدّث الكاش عند المستخدمين.

## تحسينات هندسية

- فصل الأنماط والسكربت عن الصفحة، وسياسة CSP صارمة (`script-src 'self'`) في `netlify.toml`.
- نوافذ أصلية `<dialog>` بدل `confirm` و`prompt`، وتوزيع أحداث بدل `onclick` المضمّنة.
- تنظيف البيانات المستوردة والمحمّلة (حدود الأرقام والتواريخ والمعرّفات).
- دالة `push-sync` تقبل اشتراكات خدمات الدفع المعروفة فقط.
- أيقونة `maskable` كانت مذكورة في المانيفست دون وجود ملفها، وأُضيفت.

## ما أُضيف في v5.1

- **تنبيه النسخة الاحتياطية**: تظهر بطاقة ذهبية كل 14 يومًا إن لم تُصدَّر نسخة (البيانات في المتصفح فقط)، وزر «تصدير» يسجّل تاريخ آخر نسخة.
- طلب **تخزين دائم** (`storage.persist`) لتقليل خطر حذف البيانات عند ضيق مساحة الهاتف.
- **إصلاح تنسيق**: عناوين المقاطع في «خطة التقوية» والمراجعة والسجل كانت تظهر داخل إطار بسبب تداخل صنف `.sm` مع أزرار +/−.
- **خدمة العمل دون اتصال**: لا تُخزَّن صفحات الخطأ بدل الصفحة الرئيسية، ويُرجَع خطأ شبكة نظيف بدل قيمة فارغة.
- **الإشعارات**: التنبيه الخلفي مرة واحدة يوميًا فقط؛ وإعادة الاشتراك تلقائيًا إن جدّد المتصفح الاشتراك (`pushsubscriptionchange`)؛ ودالة الإرسال لا تتعطل كلها بسبب مشترك واحد ببيانات تالفة.
- **النشر**: حجب `/netlify/*` و`package.json` و`netlify.toml` و`README.md` عن الزوار، وإضافة `404.html` و`.gitignore`.
